# WorkBuddy 黄皮书

《WorkBuddy 黄皮书：从零基础到能搭工作流》——面向中小企业与电商团队的一本通，帮助零基础用户把 AI 用进日常办公。

本书从下载、安装和第一次任务开始，逐步介绍提示词、记忆、知识库与 ima、多模态、专家与技能、连接器、自动化，以及如何把这些能力放进一条完整工作流。全书 11 章 + 6 附录。

## v2.0.0 更新要点

- **新增第 6 章「知识库与 ima」**：ima / 腾讯文档 / 乐享三类知识库的授权与接入、资料引用与范围限定、产物「上传到云端」回存闭环。
- **提示词方法升级**：四要素改为五要素（角色 / 任务 / 背景 / 要求 / 输出格式），新增「边界 + 验收」两道保险。
- **模式名称同步产品**：Craft / Plan / Ask 统一为 Agent / Plan / Ask，补充输入框「+」菜单的切换路径。
- **实战案例 6 → 9 个**：新增「用 ima 知识库写行业稿」「求职 JD 拆解 + 简历匹配」「课程笔记沉淀进知识库」；11.10 把九个案例拼成个人 AI 工作台。
- **附录扩容**：新增附录 E「下一步与延伸」（原附录 E 顺延为 F）；FAQ 19 → 26 条，术语表 15 → 19 词，速查表补入记忆文件真实路径。
- **阅读方式**：目录可点击跳转，HTML 阅读无固定页，PDF 为导出形态。
- **同步精简**：移除模型与设置、工作空间、版本与订阅等章节，页数由 104 页调整为 88 页；读者定位收窄到中小企业与电商团队。
