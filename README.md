# WorkBuddy 黄皮书

《WorkBuddy 从入门到精通》黄皮书，面向希望把 AI 用到日常办公中的用户。

本书从下载、安装和第一次任务开始，逐步介绍提示词、记忆、多模态、专家与技能、连接器、自动化，以及如何把这些能力放进一条完整工作流。
